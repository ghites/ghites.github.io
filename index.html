PersonalAssistant

PersonalAssistant is a private administrative assistant application that integrates with Google services (Gmail, Google Calendar, Google Tasks, and Google Drive) to help manage personal and professional administrative tasks.

This application is for private, personal use only. It is not available to the public and is used exclusively by the application owner.

Features

  • Email management and triage via Gmail
  • Calendar event tracking via Google Calendar
  • Task management via Google Tasks
  • Document search and filing via Google Drive
