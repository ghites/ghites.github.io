Privacy Policy for PersonalAssistant

Last updated: 21 October 2026

Application name: PersonalAssistant

1. Overview

PersonalAssistant is a private desktop application used exclusively by its owner for personal administrative tasks. It is not a public service and does not have external users.

2. Data Collection and Usage

PersonalAssistant accesses the following Google services via OAuth 2.0, solely on behalf of the application owner:

  • Gmail — reading, searching, drafting, and managing emails and labels
  • Google Calendar — reading and creating calendar events
  • Google Tasks — reading and managing tasks
  • Google Drive — searching and accessing the owner's files

The application uses these permissions exclusively to assist the owner with personal administrative tasks such as email triage, appointment scheduling, document filing, and task tracking.

3. Data Storage and Security

All data accessed by PersonalAssistant remains within the owner's Google account and local device. Specifically:

  • OAuth authentication tokens are stored locally on the owner's device in encrypted form.
  • No data is transmitted to, stored on, or shared with any third-party servers.
  • No data is collected from any user other than the application owner.
  • No analytics, tracking, or telemetry data is collected.

4. Data Sharing

PersonalAssistant does not share any data with third parties. No user data is sold, rented, or disclosed to anyone.

5. Data Retention

PersonalAssistant does not independently retain Google user data. All data remains in the owner's Google account and can be managed through standard Google account controls.

6. User Rights

The application owner can revoke PersonalAssistant's access at any time through Google Account settings at https://myaccount.google.com/permissions.

7. Contact

For any questions regarding this privacy policy, please contact: ghites@gmail.com
